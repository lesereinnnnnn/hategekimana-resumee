# Yannick Hategekimana - Responsive Portfolio (CSS Midterm)

A personal portfolio website built with semantic HTML, CSS Flexbox, CSS Grid, and media queries.

## How to open the website
1. Download or clone this repository (keep all files together in the same folder).
2. Open `index.html` in any web browser (double-click it).
3. Use the navigation bar to visit the Home, Hobbies, and Contact pages.

## Files
- `index.html`, `hobbies.html`, `contact.html` - the three pages
- `style.css` - all styling (Flexbox, Grid, media queries)
- `images/profile.jpg` - profile photo
